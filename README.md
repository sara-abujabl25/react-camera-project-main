## hand gesture meme camera
a fun side project i built using python, OpenCV and MediaPipe.<br>
the camera detects different hand gestures and shows a meme image with a sound.<br>
i used<br>
• Python<br>
• OpenCV<br>
• MediaPipe<br>
• Pygame<br>
guide_how_to_run
pip install opencv-python mediapipe pygame
python main.py
